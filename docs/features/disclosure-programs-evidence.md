# Disclosure evidence and limits

Each fetched source retains its URL, source type, status, and fetch time. Deployment records require their own evidence URL. Address comparison is exact after case normalisation; prose-only scope stays visible but is not treated as an address match.

Expired policies are flagged. Provider failure produces partial or unavailable coverage, not a “no program” claim. Reward values are shown only when explicitly published and are never inferred.
