# Circulating supply reconciliation

This read-only insight records total supply and declared non-circulating balances at one block or ledger. It subtracts only addresses that include a human-readable reason and an evidence URL. Values use integer base units, so no floating-point rounding is introduced.

The result is evidence, not a market-cap estimate. Undeclared wallets, bridges, rebasing rules, and issuer-specific semantics can make the real circulating amount differ.
