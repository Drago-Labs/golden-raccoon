# Repository continuity

Public GitHub repository activity only.

- Release cadence is the count and dates of published releases in the fixture or API page.
- Commit activity is counted inside fixed windows and is not a quality score.
- Active maintainers are people without an end date. Turnover counts maintainers who have one.
- Archived, renamed, and fork-only states are shown as observed.
- A transfer is followed once and labeled. A second hop is not walked.
- Rate-limited, not-found, and private responses are unavailable or named states, never zero activity.
- A server token is never copied into the response.
