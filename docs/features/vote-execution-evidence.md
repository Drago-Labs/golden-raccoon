# Vote execution evidence and limits

Every proposal and execution keeps its source link. The coverage notice records proposal count, execution count, executor, and scanned block range. Exact matches require target, calldata, and value; target-only matches are shown as different.

Multiple exact candidates are labelled ambiguous rather than selected arbitrarily. Provider failure is unavailable, not clean. Events outside the range, proxy indirection, multisig batching, or missing proposal payloads can prevent a match.
