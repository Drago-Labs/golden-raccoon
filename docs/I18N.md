# Locale support

History uses typed English and Turkish message catalogs and shared Intl formatters. A valid `gr-locale` preference overrides weighted Accept-Language; unsupported inputs fall back to English. The language selector also stores the browser time zone in `gr-time-zone`; invalid or missing time zones use UTC. Formatting changes presentation only: token symbols, transaction hashes, network identifiers and stored timestamps remain unchanged.

Use `messages(locale)` for catalog keys and `createFormatters(locale, timeZone)` for displayed values. Percent inputs are fractions (0.42 means 42%). Missing keys are compile-time errors and are also rejected at runtime. Turkish covers the history catalog; provider-generated summaries and other routes are not translated by this change.

Run `node --import tsx scripts/history-i18n-check.ts` from frontend. Full-application extraction and a hardcoded-copy lint gate remain follow-up work.
